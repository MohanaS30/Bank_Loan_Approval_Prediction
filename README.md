# Bank Loan Approval Prediction

## Project Overview

This project predicts whether a loan application will be approved or rejected using Data Science and Machine Learning techniques.

The project analyzes applicant-related information such as income, credit history, education, employment status, loan amount, and property area to identify patterns related to loan approval.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Machine Learning Models

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier
* K-Nearest Neighbors (KNN)

## Project Workflow

1. Data Loading
2. Data Cleaning and Preprocessing
3. Label Encoding and One-Hot Encoding
4. Exploratory Data Analysis
5. Feature Scaling
6. Train-Test Split
7. Model Training
8. Model Evaluation
9. ROC-AUC Analysis
10. Loan Approval Prediction

## Evaluation Metrics

The models are evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
* ROC-AUC

## Project Outcome

The trained machine learning models are used to predict the loan approval status of new loan applications.
